# CapCut 法国市场：最后一公里

一个面向 AI 产品运营、用户研究和国际化内容岗位的独立工作样本。

**Live:** <https://xixiyiyiyi.github.io/capcut-fr-signal/>

## 这份作品在做什么

我没有把“法国市场”写成一份泛行业报告，而是从一个可被追问的产品问题开始：当用户已经完成剪辑，为什么最后一步仍然可能变成损失？

基于 Apple App Store 法国区近期公开评论，我做了三件事：

1. 抓取 CapCut 300 条近期公开评论，并与 InShot、VN、Canva 做同窗口对照；
2. 把价格、导出/画质、可靠性相关信号分开，保留原文和中文摘译；
3. 把信号转成一个可被证伪的产品楔子：导出前的法语 preflight，以及一个 90 天验证计划。

核心判断：**先验证交付确定性，不先做又一个生成功能。**

## 这不是什么

- 不是 CapCut 客户项目；
- 不是 CapCut 已上线功能；
- 不是用户访谈、转化、收入或留存数据；
- 不代表全部法国用户。

公开评论天然偏负面，RSS 不是随机抽样，不同 App 的样本量也不同。这里展示的是如何从噪声中提出一个更窄、更可验证的假设。

## 文件

- `index.html`：完整案例页；

- `assets/qr.png`：线上地址二维码；
- `assets/qr-resume-card.png`：简历角落用的二维码卡片。
